# Contributing

Thank you for wanting to help! Contributions are welcome, including bug fixes, optimizations, and improvements.


## Before You Start

Please contact me first, especially for bigger changes or if you need help with the build setup. I am happy to help, and it saves us both time.

- **Nexus Mods:** Comments on the official mod page (see [README.md](README.md))
- **Discord:** My Discord server (see [README.md](README.md))

> **Note:** GitHub issues are for **bug reports only**. Please do not use them for questions or feature suggestions.


## How to Contribute

1. **Fork** the repository on GitHub.
2. **Run `update_submodules.bat`** right after cloning, then make your changes (see *"Building from Source"* in the [README.md](README.md)).
3. **Test** your changes in the game.
4. **Open a Pull Request** and describe what you changed and why.

> **Code Quality & Scope:** Please keep your changes focused and follow the style of the existing code. Submissions that do not meet these standards may be modified or refactored prior to merging, or, at worst, rejected.
